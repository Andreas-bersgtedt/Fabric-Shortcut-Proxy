# Documentation Archive

This directory holds dated design records, planning snapshots, and implementation
reviews. They explain decisions made during development but do not define current
runtime behavior, defaults, deployment steps, or support procedures.

For maintained documentation, start with [the user manual](../manual/README.md).
Use [CONFIGURATION.md](../CONFIGURATION.md), [SECURITY.md](../SECURITY.md),
[TechnicalArchitecture.md](../TechnicalArchitecture.md), and the deployment
guides for current reference material.

| Document | Archived role |
| --- | --- |
| `ASCII_INSTALLER_PLAN.md` | Original Linux installer design |
| `CONFIG_BUILDER_PLAN.md` | Superseded Config Builder design |
| `FRESHNESS_PLAN.md` | Early freshness design record |
| `initial_feature_review.md` | July 2026 C++ Agent review |
| `Open_Mirror_Tokenization_Plan.md` | Open Mirror tokenization implementation plan |
| `PLANNING.md` | POC hardening roadmap |
| `Roadmap.md` | July 2026 roadmap snapshot |

`SCALE_ARCHITECTURE_PLAN.md` remains at the `docs/` root because the User Manual
links to it. It is also a historical design proposal, not an operator reference.
