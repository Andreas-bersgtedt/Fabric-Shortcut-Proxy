# Fabric Shortcut Proxy Enterprise

This package adds the scale-out control plane to Fabric Shortcut Proxy Lite:

- Manager and Agent control links;
- durable materialization queue and elastic membership;
- fenced active/passive Manager HA;
- fleet supervision, gateway, monitoring, and retention services.

Install the matching Lite package first. Enterprise 2.10.0 requires
`fabric-shortcut-proxy==2.10.0`.
